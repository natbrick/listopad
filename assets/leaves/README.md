# Акварельные иллюстрации листьев

В каталоге используются оригинальные PNG из `listopad_26_leaves.zip`, а также оригинальный рисунок красного дуба `red-oak.png`. Все 27 файлов перечислены в `data/species.json` со статусом `ready`; рисунки не изменялись.

Файлы и соответствующие им записи:

`американский клен.png` → `american-maple`; `барбарис.png` → `barberry`; `береза.png` → `birch`; `боярышник.png` → `hawthorn`; `вяз.png` → `elm`; `девичий виноград.png` → `virginia-creeper`; `дуб.png` → `oak`; `ива.png` → `willow`; `калина.png` → `viburnum`; `клен.png` → `maple`; `конс каштан.png` → `horse-chestnut`; `лещина.png` → `hazel`; `липа.png` → `linden`; `маньчжурский орех.png` → `manchurian-walnut`; `облепиха.png` → `sea-buckthorn`; `ольха.png` → `alder`; `осина.png` → `aspen`; `пестролистый дёрен.png` → `variegated-dogwood`; `рябина.png` → `rowan`; `сирень.png` → `lilac`; `тополь.png` → `black-poplar`; `черемуха.png` → `bird-cherry`; `черноплодная рябина.png` → `chokeberry`; `шиповник.png` → `rosehip`; `яблоня.png` → `apple`; `ясень.png` → `ash`; `red-oak.png` → `red-oak`.
