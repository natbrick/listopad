# Листопад: угадай дерево

Локальная браузерная игра без сборщика и сторонних зависимостей.

## Запуск

Из корня проекта запустите:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000` в браузере. Сервер нужен, чтобы браузер мог загрузить справочник видов из `data/species.json`.

## Содержимое

- Два режима: «Знаток» (14 случайных листьев из 27) и «Супер-знаток» (все 27 листьев); в каждом вопросе показывается один лист.
- После правильного ответа открывается факт о растении; прогресс, счёт и коллекция сохраняются в `localStorage`.
- Русские и научные названия, словесные подсказки и факты собраны в `data/species.json`.
- В справочнике ровно 27 видов; груша и вишня исключены, клёны остролистный и ясенелистный, дёрен пестролистный, а также красный и черешчатый дубы представлены отдельно.
- 26 оригинальных акварельных PNG распакованы из `listopad_26_leaves.zip`, а рисунок красного дуба добавлен отдельно; все 27 иллюстраций подключены в `data/species.json`. Список файлов и соответствий приведён в `assets/leaves/README.md`.
